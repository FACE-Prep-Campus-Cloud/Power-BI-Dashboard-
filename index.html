Connect your Google Sheet

This board can read and write directly to your sheet using a small Google Apps Script "Web app" — no separate server needed. One-time setup:

  1. Open your sheet, then go to Extensions → Apps Script.
  2. Delete any starter code and paste in the script below.
  3. Deploy → New deployment → type Web app → Execute as Me, Who has access: Anyone with the link → Deploy (approve the permissions prompt).
  4. Copy the Web app URL it gives you and paste it below.

Note: anyone with this URL can read and write this sheet's task data — keep it as private as you would the sheet itself.
